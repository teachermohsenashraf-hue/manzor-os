# خط ثمانية

ملفات الخط غير مضمّنة في المستودع العام لأن الترخيص يمنع إعادة توزيعها كملفات مستقلة

بعد تنزيل الخط من موقع ثمانية الرسمي وفق الترخيص، ضع الملفات التالية في هذا المجلد قبل البناء

- `thmanyahserifdisplay-Regular.woff2`
- `thmanyahserifdisplay-Bold.woff2`
- `thmanyahserifdisplay-Black.woff2`

الملفات الموجودة محليًا عند المالك تبقى خارج Git ولا يُرفع منها شيء
