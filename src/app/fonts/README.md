# خط ثمانية

ملفات الخط غير مضمّنة في المستودع العام لأن الترخيص يمنع إعادة توزيعها كملفات مستقلة

الواجهة المنشورة تستخدم ملفات Thmanyah Serif Display الثلاثة من النطاق الذي تستخدمه صفحة الخط الرسمية `font.thmanyah.com`. لذلك لا يحتاج بناء Vercel إلى هذه الملفات المحلية

إذا رغبت في تشغيل نسخة محلية دون اتصال بالإنترنت، نزّل الخط من موقع ثمانية الرسمي وفق الترخيص وضع الملفات التالية في هذا المجلد، ثم غيّر روابط `@font-face` محليًا فقط

- `thmanyahserifdisplay-Regular.woff2`
- `thmanyahserifdisplay-Bold.woff2`
- `thmanyahserifdisplay-Black.woff2`

الملفات الموجودة محليًا عند المالك تبقى خارج Git ولا يُرفع منها شيء
